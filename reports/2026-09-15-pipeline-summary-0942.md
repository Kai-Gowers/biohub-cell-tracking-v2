# The 0.942 replica pipeline (branch `replicate-0942`), in one page

**Pipeline:** TemporalUNet3D + node transformer (one joint model, two seeds) -> tracksdata ILP -> notebook post-processing (deterministic repair) -> one `.geff` per video -> `submission.csv`. Faithful port of the public pilkwang pack plus the 0.942 notebook's six inference patches; bit-exact against the reference on two held-out videos (nodes, edges, edge_prob).

**Data:** 3D+time zarr (100 x 64 x 256 x 256 uint16) + sparse geff labels (~3% of cells). Voxel 1.625 µm in z, 0.406 µm in xy. Each *video* is normalised with its own 0.001 / 0.999 intensity quantiles from the zarr attrs, then decimated 4x in xy only -> isotropic 1.625 µm grid (64 x 64 x 64). No mean-pooling. Output coordinates are `grid index x 4`, no half-cell offset.

**Model (2.1 M params):** shared 3D U-Net (32/64/128 channels, BatchNorm/ReLU) on 2-frame windows, with per-voxel multi-head attention across the two frames at the two coarser stages. 32 feature channels per frame, one detection channel.
- *Center head:* per-voxel logit; detections = `sigmoid > 0.965` local maxima under a (3,3,3) max-pool (3 µm) on the 1.625 µm grid.
- *Edge head:* node features gathered from the U-Net map at each detection + sinusoidal position features -> 4 alternating cross-attention blocks (t -> t+1, t+1 -> t, hidden 128) -> pair MLP on `[h_src, h_tgt, (coord_src - coord_tgt)/100]` -> full n_src x n_tgt logit matrix. **All pairs are scored, no distance gate**; softmax over *parents* per child, candidates kept above 0.48 (dual seed) / 0.50 (single). The transformer sees every detection in both frames, so it learns local flow and neighbour context implicitly.

**Inference patches (cell 16):** 8-view planar D4 detection TTA in logit space (z never flipped); edge-feature TTA over the same 8 views; second-seed model blended 0.2 / 0.8 on detections (moment-matched) and by low-margin consensus on edges, with a per-frame fallback to the primary if the blend keeps < 90% of its peaks; bidirectional harmonic fusion of forward and reverse edge logits (w = 0.15).

**ILP (tracksdata / SCIP via ilpy, from the pack wheels):** binary variables per node, edge, appearance, disappearance, division; flow conservation gives in-degree <= 1, out-degree <= 2. Objective `-1.0 x edge_prob` per edge, appearance 0.0, disappearance 2.0, division 1.2. No minimum edge score. The ILP's edges are discarded downstream; what survives is the node set and the `edge_prob` table.

**Repair (cell 18, in order):** edge sanity (dt = 1, <= 14 µm) -> motion relink (**replaces every ILP edge** by a velocity-model assignment, 5.5 µm tight / 10 µm relaxed, learned bonus 1.0) -> single-parent repair -> gap-1 closing (5.8 µm, density-adaptive, synthetic midpoint refined on intensities; DeepCenter model vetoes synthetic nodes spanning >= 8.5 µm unless score > 0.25) -> gap-2 recovery (<= 10.2 µm total, 4.4 µm per step, capped at 0.45% of links) -> safe divisions (parent <= 9 µm, sisters <= 14 µm, capped at 0.76% per frame) -> prune isolated -> short-track filter (< 6 frames) with adaptive rescue -> line-fit smoothing of coordinates only. All edges end up dt = 1. This is the only stage that emits divisions.

**Training (the pack recipe, ported):** AdamW 1e-4, no scheduler, clip 1.0, batch 8 full-frame windows, brightness shift +-0.1 and independent z/y/x flips, 400 epochs. Loss = edge + 1.0 x detection. Detection: one-hot weighted BCE (`w_pos = 1/n_pos`, `w_neg = 0.01/n_neg`). Edge: targets from detect-and-match on the live logits (logit > 0.3, 5 µm match), focal softmax-over-parents BCE on annotated rows/columns; unmatched detections act as decoys. Ours trains on 179 videos, holds out 20 (5 `44b6`, 15 `6bba`), selects `_best` by the competition metric at the ILP stage; the public weights used all 199. Two seeds (0, 314159) on 4 L40S via DDP, ~6 min/epoch.

**Score:** edge Jaccard + 0.1 x division Jaccard, 7 µm node match, minus a node-count penalty. Sparse GT ignores ~96% of predicted edges, so over-linking is invisible locally. Local scores are only reliable for same-checkpoint config comparisons; cross-checkpoint comparisons were anti-correlated with the leaderboard in the previous repo. Shipped weights on our 20 held-out videos: 0.9175 (train-set number); our own seeds at epoch ~260: 0.865-0.870 held-out, `44b6` ~0.75 / `6bba` ~0.88.
